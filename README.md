# División de factura

Página para repartir una factura de EDESA / Aguas del Norte / LUSAL entre dos inquilinos, al centavo exacto.

Abrí `index.html` en el navegador, cargá el PDF de la factura (los datos se completan solos), poné el consumo de la persona 1 y calculá. La energía se reparte por tramos: cada persona tiene la mitad de los tramos de 70 y 130 kWh. Todos los cálculos se hacen en centavos, así la suma de las dos personas da exactamente el total de la factura.
